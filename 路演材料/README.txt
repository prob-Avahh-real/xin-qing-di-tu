========================================
心情地图 - 路演材料清单
========================================

一式两份：飞书文档 + 路演PPT

----------------------------------------
一、飞书文档（项目介绍）
----------------------------------------

文件1: 心情地图-飞书文档.md
格式: Markdown
用途: 直接复制粘贴到飞书文档
大小: 约10KB

文件2: 心情地图-飞书文档.pdf
格式: PDF (已生成)
用途: 打印、邮件附件、离线阅读
大小: 约900KB

文件3: 心情地图-飞书文档-PDF版.html
格式: HTML
用途: 如需重新生成PDF，用Chrome打开→打印→另存为PDF
说明: 样式已优化，支持分页

----------------------------------------
二、路演PPT（3分钟演示）
----------------------------------------

文件4: 心情地图-路演PPT.html
格式: HTML演示文稿
用途: 
  - 浏览器直接演示（按←→键翻页）
  - Chrome打印为PDF（选择"另存为PDF"）
大小: 约17KB

文件5: 心情地图-路演PPT-Marp.md
格式: Marp Markdown
用途: 可用Marp工具导出为PPTX
安装Marp: npm install -g @marp-team/marp-cli
导出命令: marp 心情地图-路演PPT-Marp.md --pptx

文件6: 演讲稿-3分钟.md
格式: Markdown
用途: 路演逐字稿，精确到秒
大小: 约5KB

----------------------------------------
使用建议
----------------------------------------

飞书文档:
1. 首选: 直接复制 .md 文件内容到飞书
2. 备选: 使用 .pdf 文件作为附件

路演PPT:
1. 首选: 浏览器打开 .html 文件，全屏演示
2. 打印PDF: Chrome打开 → 打印 → 另存为PDF
3. PPTX: 使用 Marp 工具导出 (npm install -g @marp-team/marp-cli)

演讲准备:
1. 打印演讲稿，标注重点句子
2. 多次演练，控制3分钟时间
3. 准备Demo环境备份（截图/视频）
