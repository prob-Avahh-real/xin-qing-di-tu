# 🗺️ 心情地图 MoodMap

**赛道**：青年出行新体验（Track 3.2）  
**Slogan**：今天是什么心情，就去哪里玩  
**定位**：情感出行指南 × AI个性化 × 在地文化  

---

## 一、一句话介绍

心情地图是专为青年群体设计的**情感化出行指南APP**，通过AI智能分析用户当下心情，生成个性化游玩路线，让每一次出行都有温度、有陪伴、有惊喜。

**核心价值**：不是导航工具，是懂你的情绪出行搭子。

---

## 二、痛点洞察与解决方案

### 🔍 三大真实痛点

| 痛点 | 场景描述 | 传统方案缺陷 |
|-----|---------|------------|
| **不知道去哪** | 周末想出门，打开攻略APP千篇一律 | 只推荐"热门景点"，不关心"什么心情去" |
| **到了就走** | 到龙华寺拍照5分钟就走 | 缺乏情感连接，没有沉浸式体验 |
| **孤单无陪伴** | 一个人出游没人讲解，没人分享 | 冷冰冰的导航语音，没有互动感 |

### 💡 心情地图解决方案

**核心理念**：**情绪出行**——业内首创根据心情推荐路线的理念。

```
用户选择情绪 → AI分析偏好 → 生成定制路线 → 语音陪伴导览 → 打卡赚积分 → 兑换文创
```

**龙华场景深度契合**：
- 龙华90路公交沿线：龙华寺、塔院、烈士陵园、艺术街区
- 青年白领下班后EMO疗愈场景
- 周末好友聚会打卡场景
- 情侣约会浪漫场景

### 🤖 AI智能推荐引擎

**技术实现**：
- 豆包API大模型编排
- 用户画像分析（情绪+时间+天气+位置）
- 动态路线生成（8-12个景点，2-4小时）
- 实时语音导览（青春活力少女音）

**示例体验**：
> 用户选择"EMO治愈" → AI生成禅意路线 → "欢迎来到龙华寺，这里是千年古刹，超级灵验哦！"

## 四、技术架构

### 🏗️ 系统架构

```
┌─────────────────────────────────────────────────┐
│                   用户层 (PWA)                    │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐          │
│  │ 情绪选择 │ │ 路线展示 │ │ 语音导览 │          │
│  └─────────┘ └─────────┘ └─────────┘          │
└─────────────────────────────────────────────────┘
                      │
┌─────────────────────────────────────────────────┐
│                  AI Agent层                      │
│  ┌─────────────┐ ┌─────────────┐              │
│  │ 豆包API     │ │ 路线规划Agent│              │
│  │ 大模型编排  │ │ 语音合成Agent│              │
│  └─────────────┘ └─────────────┘              │
└─────────────────────────────────────────────────┘
                      │
┌─────────────────────────────────────────────────┐
│                  数据服务层                      │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐          │
│  │高德地图 │ │POI数据库│ │用户数据 │          │
│  └─────────┘ └─────────┘ └─────────┘          │
└─────────────────────────────────────────────────┘
```

### 🔧 核心技术栈

| 技术 | 应用场景 | 亮点 |
|-----|---------|------|
| **PWA** | 渐进式Web应用 | 可安装到桌面，离线可用，原生APP体验 |
| **豆包API** | AI对话+语音合成 | 青春活力少女音，像朋友一样陪伴 |
| **高德地图** | 地图+导航 | 精准定位，AR导航能力 |
| **Vue3+Vite** | 前端框架 | 组件化开发，快速迭代 |
| **Pinia** | 状态管理 | 路线状态、用户数据全局共享 |

### 📱 产品形态

**PWA（渐进式网页应用）**：
- ✅ 无需下载安装，扫码即用
- ✅ 可添加到手机桌面，无浏览器地址栏
- ✅ 离线可用，断网也能查看已加载内容
- ✅ 消息推送能力（未来扩展）
