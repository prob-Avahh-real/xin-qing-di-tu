🔧 飞书 Webhook 配置

💡 从飞书机器人设置中获取 Webhook 地址

📖 飞书配置指南

1️⃣ 创建飞书机器人

1. 打开飞书群组 → 点击右上角设置

2. 选择"添加机器人" → "自定义机器人"

3. 设置机器人名称（如：心情地图助手）

4. 复制 Webhook 地址

2️⃣ 配置安全设置

⚠️ 飞书要求机器人必须配置安全设置：

• 方式 1: 设置签名密钥（推荐）

• 方式 2: 设置 IP 白名单

• 方式 3: 设置关键词（简单但不够安全）

3️⃣ 测试推送

1. 在上方填写 Webhook URL

2. 选择消息类型（推荐富文本）

3. 输入测试内容

4. 点击"测试推送"

5. 检查飞书群是否收到消息

📌 常见错误

• 400 Bad Request: Webhook URL 错误或格式不对

• 401 Unauthorized: 签名密钥错误或未配置

• 403 Forbidden: IP 不在白名单

• Network Error: 网络问题或跨域限制

🔐 签名密钥配置（可选）

💡 如果飞书机器人配置了签名密钥，需要填写此项
💡 如果飞书机器人配置了关键词，消息必须包含此词
