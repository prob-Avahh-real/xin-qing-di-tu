## ⚙️ 高级选项

### 跳过某些安装步骤

**只安装应用（不安装 Ollama）**:
```powershell
.\install.ps1 -SkipOllama
```

**跳过模型下载**（适合网络慢的情况）:
```powershell
.\install.ps1 -SkipModel
```

**完全跳过 Ollama 和模型**:
```powershell
.\install.ps1 -SkipOllama -SkipModel
```

## 🔧 故障排除

### 问题 1: 权限不足

**错误**: "需要管理员权限"

**解决**:
```
右键 install.bat → 以管理员身份运行
```

---

### 问题 2: Node.js 安装失败

**错误**: "Node.js 安装失败"

**解决**:
```
方法 1: 手动安装
  1. 访问 https://nodejs.org/
  2. 下载 LTS 版本
  3. 安装后重新运行 install.bat

方法 2: 使用 winget
  winget install OpenJS.NodeJS.LTS
```

---

### 问题 3: Ollama 下载慢

**错误**: "Ollama 下载超时"

**解决**:
```
方法 1: 使用国内镜像
  编辑 install.ps1，修改下载链接为国内镜像

方法 2: 手动下载安装
  1. 访问 https://ollama.com/
  2. 下载安装器
  3. 运行安装器
  4. 重新运行 install.bat
```

---

### 问题 4: 模型下载失败

**错误**: "模型下载失败"

**解决**:
```
方法 1: 稍后手动下载
  ollama pull qwen2.5:7b

方法 2: 使用较小模型
  ollama pull llama3.2:3b

方法 3: 跳过模型下载
  .\install.ps1 -SkipModel
  （应用仍可使用，但无 AI 对话功能）
```

---

### 问题 5: 端口被占用

**错误**: "端口 5173 已被占用"

**解决**:
```
方法 1: 关闭占用端口的程序
  netstat -ano | findstr :5173
  taskkill /PID <PID> /F

方法 2: 修改应用端口
  编辑 package.json，修改 dev 脚本的端口
```

---

### 问题 6: 应用无法启动

**错误**: "应用启动失败"

**解决**:
```
方法 1: 手动启动
  1. 打开命令提示符
  2. cd C:\Users\你的用户名\LonghuaVoiceGuide
  3. npm run dev

方法 2: 查看日志
  检查控制台输出的错误信息
```

## 🎯 卸载方法

### 方法 1: 使用卸载程序

```powershell
# 运行卸载脚本
.\uninstall.ps1
```

### 方法 2: 手动卸载

```
步骤 1: 删除安装目录
  C:\Users\你的用户名\LonghuaVoiceGuide\

步骤 2: 删除快捷方式
  - 桌面：龙华·灵境向导.lnk
  - 开始菜单：龙华·灵境向导.lnk

步骤 3: （可选）卸载 Ollama
  设置 → 应用 → Ollama → 卸载

步骤 4: （可选）卸载 Node.js
  设置 → 应用 → Node.js → 卸载
```
