## 🚀 部署到网上（3 种方法）

### 方法 1: Vercel（推荐）⭐⭐⭐⭐⭐

**优势**:
- ✅ 完全免费
- ✅ 自动 HTTPS
- ✅ 全球 CDN
- ✅ 1 分钟部署
- ✅ 自定义域名

**步骤**:

```powershell
# 1. 安装 Vercel CLI
npm install -g vercel

# 2. 登录（首次需要）
vercel login

# 3. 进入项目目录
cd E:\hackathon-travel-experience-main

# 4. 部署手机版
vercel --prod

# 5. 获得链接
# 例如：https://longhua-guide.vercel.app
```

**创建 vercel.json 配置**:

```json
{
  "version": 2,
  "builds": [
    {
      "src": "mobile-ultra-lite.html",
      "use": "@vercel/static"
    }
  ],
  "routes": [
    {
      "src": "/",
      "dest": "/mobile-ultra-lite.html"
    }
  ]
}
```

**输出示例**:
```
🔍  Inspect: https://vercel.com/your-project/xxx
✅  Production: https://longhua-guide.vercel.app
```

**手机访问**:
```
1. 浏览器打开：https://longhua-guide.vercel.app
2. 或扫描二维码（Vercel 自动生成）
```

### 方式 2: 扫码访问

**生成二维码**:

```powershell
# 方法 1: 在线生成
访问：https://www.qr-code-generator.com/
输入链接 → 下载二维码

# 方法 2: 用 Python
import qrcode
url = "https://longhua-guide.vercel.app"
img = qrcode.make(url)
img.save("qrcode.png")

# 方法 3: 用 Node.js
npm install qrcode
npx qrcode "https://longhua-guide.vercel.app" > qrcode.png
```

**打印二维码**:

## 🌐 国内访问优化

### 问题

Vercel/Netlify 在国外，国内访问可能慢。

### 解决方案

**方案 A: 阿里云 OSS（推荐）**

```
1. 注册阿里云账号
2. 创建 OSS Bucket
3. 上传 mobile-ultra-lite.html 为 index.html
4. 开启静态网站托管
5. 绑定自定义域名（可选）

费用：约 10 元/月
速度：国内 CDN，非常快
```

**方案 B: 腾讯云 COS**

```
类似阿里云 OSS
费用：约 10 元/月
```

**方案 C: 七牛云**

```
免费额度：10GB 存储 + 10GB 流量/月
适合小项目
```
