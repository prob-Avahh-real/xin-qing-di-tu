## 1️⃣ 普通游客（核心用户）

### 入口
**文件**: `business-pro-rich-routes.html`

### 用户旅程

```
第 1 步：打开主 APP
        ↓
第 2 步：选择心情（12 种情绪按钮）
        ↓
第 3 步：AI 生成个性化路线（8-12 个景点）
        ↓
第 4 步：查看路线详情（地图 + 景点卡片）
        ↓
第 5 步：点击"开始游玩"
        ↓
第 6 步：导航到第 1 个景点
        ↓
第 7 步：打卡拍照 → 获得积分
        ↓
第 8 步：继续下一个景点...
        ↓
第 9 步：游玩结束 → 兑换积分奖励
```

### 功能模块

| 功能 | 文件 | 用途 |

| **主 APP** | business-pro-rich-routes.html | 12 情绪路线生成 |
| **积分商城** | points-mall-app-fixed.html | 积分兑换奖励 |
| **知识库** | knowledge-base.html | 龙华历史文化 |
| **许愿池** | wishing-pool.html | 时间胶囊许愿 |
| **POI 详情** | poi-detail.html | 景点详细介绍 |
| **停车引导** | 停车引导 - 极简版.html | 智能停车推荐 |

## 2️⃣ 商户/服务商（合作伙伴）

### 入口
**文件**: `merchant-partnership.html`

### 入驻流程

```
第 1 步：打开商户端入口
        ↓
第 2 步：填写入驻申请表
        - 商户名称
        - 联系人
        - 电话
        - 地址
        - 营业执照
        ↓
第 3 步：提交审核
        ↓
第 4 步：等待管理员审核（1-3 工作日）
        ↓
第 5 步：审核通过 → 获得商户账号
        ↓
第 6 步：登录商户后台
        ↓
第 7 步：发布优惠券/活动
        ↓
第 8 步：查看核销数据/收益
```

### 商户类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **餐饮商户** | 餐厅、咖啡厅、小吃店 | 龙华寺素斋馆 |
| **文创商户** | 文创店、手作店、书店 | 塔影空间 |
| **体验商户** | DIY 体验、工作坊 | 传统手工艺体验 |
| **住宿商户** | 民宿、酒店 | - |
| **交通商户** | 停车场、租车 | 塔影空间地下车库 |

### 商户功能

**商户后台**:
- 发布优惠券
- 创建活动
- 查看核销数据
- 收益提现
- 评价管理

**收益模式**:
- 优惠券核销 → 获得佣金
- 活动报名 → 获得收入
- 会员充值 → 获得现金流

## 4️⃣ 管理员（运营团队）

### 入口
**文件**: `admin-dashboard.html`

### 管理功能

#### A. 商户审核

```
待审核商户列表
        ↓
查看商户资料
        ↓
审核通过 / 拒绝
        ↓
发送通知
```

#### B. 路线审核

```
用户/商户提交的路线
        ↓
审核内容质量
        ↓
通过 → 上线展示
拒绝 → 说明原因
```

#### C. 活动审核

```
商户提交的活动
        ↓
审核活动内容
        ↓
通过 → 允许发布
拒绝 → 修改建议
```

#### D. 数据看板

**核心数据**:
- 日活用户数
- 路线生成次数
- 积分发放/消耗
- 商户入驻数量
- 优惠券核销率
- 营收数据
