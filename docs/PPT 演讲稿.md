## Slide 2: 痛点分析

# 😔 现代年轻人的出行之痛

### 你是否也这样？

- ❌ 想去玩，但不知道去哪里 → **选择困难**

## Slide 9: 技术架构

# 🛠️ 技术栈

## 核心技术

```
Vue 3 + TypeScript + Vite + Tailwind CSS
高德地图 API + Web Speech API
PWA + Service Worker + localStorage
```

## 技术亮点

- ✅ **PWA 支持**：可安装到手机桌面，离线可用
- ✅ **语音合成**：浏览器原生，无需后端
- ✅ **数据持久化**：localStorage 离线存储
- ✅ **响应式设计**：手机/平板/PC 全适配

## 项目规模

```
📁 15 个 HTML 文件
📄 10 个文档文件
💻 约 250KB 代码
⏱️ 2 天开发完成
```
