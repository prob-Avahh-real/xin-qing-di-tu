## 🔧 安装步骤

### 步骤 1：传输文件到远程电脑

#### 方法 A：远程桌面直接复制（推荐）

```
1. 打开远程桌面连接
   - Win + R → 输入 mstsc → 回车

2. 连接前配置本地资源
   - 点击"显示选项"
   - 切换到"本地资源"选项卡
   - 点击"本地设备和资源"下的"详细信息"
   - 勾选"驱动器"
   - 勾选你的本地硬盘（包含 E 盘）
   - 确定

3. 连接远程电脑
   - 输入远程电脑 IP 或计算机名
   - 输入用户名和密码
   - 连接

4. 复制文件
   - 在远程电脑上打开"此电脑"
   - 找到你的本地 E 盘（会显示为"E 在 [你的计算机名] 上"）
   - 进入 E:\hackathon-travel-experience-main\
   - 复制 心情地图 - 完整文件包（明亮版）.zip
```

#### 方法 B：网盘传输

```
1. 在本地电脑上传
   - 打开百度网盘/阿里云盘/腾讯微云
   - 上传 心情地图 - 完整文件包（明亮版）.zip

2. 在远程电脑下载
   - 打开网盘
   - 下载文件到 D 盘临时位置
```

#### 方法 C：微信/QQ 文件传输

```
1. 在本地电脑发送
   - 打开微信/QQ
   - 拖拽文件到文件传输助手
   - 发送

2. 在远程电脑接收
   - 打开微信/QQ
   - 下载文件
   - 保存到 D 盘
```

---

### 步骤 2：在 D 盘创建安装目录

```
1. 打开"此电脑"
2. 进入 D 盘
3. 右键 → 新建 → 文件夹
4. 命名为：心情地图
5. 完整路径：D:\心情地图\
```

## 🔧 常见问题

### Q1: 双击后没有反应？

**A**:
```
1. 检查是否安装了浏览器
2. 右键 → 打开方式 → 选择浏览器
3. 如果还不行，重新安装浏览器
```

### Q2: 语音播放不了？

**A**:
```
1. 检查电脑音量是否打开
2. 检查浏览器是否静音
3. 刷新页面试试
4. 更换 Chrome 或 Edge 浏览器
```

### Q3: 页面显示不正常？

**A**:
```
1. 按 F12 刷新页面（清除缓存）
2. 更换浏览器
3. 确认所有文件都已解压
```

### Q4: 快捷方式图标不对？

**A**:
```
这是正常的，HTML 文件快捷方式会用浏览器图标
不影响使用，双击即可打开
```
