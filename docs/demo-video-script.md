## 录制要点

### 技术准备
1. **屏幕录制**: OBS Studio 或 Loom
2. **分辨率**: 1920x1080 (1080p)
3. **帧率**: 30fps
4. **音频**: 外接麦克风，消除背景噪音

### 录制技巧
1. **提前练习**: 每个操作练习3-5遍
2. **节奏控制**: 保持快节奏，避免长时间停顿
3. **鼠标轨迹**: 使用鼠标高亮工具 (如PointerFocus)
4. **转场效果**: 使用简单的淡入淡出

### 后期制作
1. **剪辑软件**: DaVinci Resolve 或剪映
2. **字幕添加**: 自动生成 + 手动校对
3. **背景音乐**: 选择无版权电子音乐
4. **色彩校正**: 统一色调，提高对比度

---

## 备用方案

### 如果录制时间紧张
1. **分段录制**: 按功能分段录制，后期拼接
2. **配音后期**: 先录屏幕操作，后配旁白
3. **使用模板**: 使用视频模板快速制作

### 如果遇到技术问题
1. **地图加载慢**: 提前缓存地图区域
2. **按钮不响应**: 使用预录的成功片段
3. **分享功能问题**: 使用静态图片演示分享效果
