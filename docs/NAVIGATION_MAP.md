### 商家入驻流程

```
第 1 步：访问商户端
   ↓
   merchant-partnership.html
   ↓
第 2 步：填写合作申请
   │
   ├─ 商户类型（餐饮/咖啡/景点/零售/体验/住宿）
   ├─ 商户名称
   ├─ 联系人信息
   ├─ 店铺地址
   ├─ 营业时间
   ├─ 店铺简介
   └─ 上传资质（营业执照、许可证）
   ↓
第 3 步：提交申请
   │
   数据保存到 localStorage
   状态：待审核
   ↓
第 4 步：等待审核
   │
   审核时间：1-3 个工作日
   查询进度：商户端 → 审核进度标签页
   ↓
第 5 步：管理员审核
   ↓
   admin-dashboard.html (管理后台)
   ├─ 查看申请列表
   ├─ 审核资质
   ├─ 批准/拒绝
   └─ 填写审核意见
   ↓
第 6 步：审核结果
   │
   ├─ ✅ 通过 → 商家状态变为"已认证"
   │   └─ 解锁功能：
   │       ├─ 查看收益数据
   │       ├─ 管理优惠活动
   │       └─ 查看客户分析
   │
   └─ ❌ 拒绝 → 商家状态变为"已拒绝"
       └─ 可重新提交申请
   ↓
第 7 步：正式合作
   │
   ├─ 签约确认
   ├─ 上线运营
   └─ 开始接待游客
```

## 🔗 页面跳转关系

### 主 APP 内部跳转

```
business-pro-rich-routes.html
│
├─ 点击情感卡片 → 开始路线体验
│   └─ 播放语音 → tts-v2.ts (playEmotionalTTS)
│
├─ 点击景点 → poi-detail.html
│   ├─ 传参：poiId (景点 ID)
│   └─ 传参：emotion (情感类型)
│
├─ 点击"赚积分" → points-mall.html
│   └─ 显示可完成任务
│
└─ 点击"分享" → share-generator.html
    └─ 生成分享图片
```

### POI 详情页跳转

```
poi-detail.html?poiId=longhua_temple&emotion=pray
│
├─ 点击"语音讲解" → 播放 TTS
│   └─ playEmotionalTTS(story, emotion)
│
├─ 点击"开始挑战" → 启动 AR 扫描
│   └─ ARScanner.vue
│
├─ 点击"发送弹幕" → 发布到弹幕墙
│   └─ 保存到 localStorage
│
└─ 点击"返回" → 回到主 APP
    └─ history.back()
```

### 商户端跳转

```
merchant-partnership.html
│
├─ 点击"合作申请"标签 → 显示申请表单
│   └─ 提交 → 保存到 localStorage
│
├─ 点击"审核进度"标签 → 显示审核状态
│   └─ 读取 localStorage 状态
│
└─ 点击"数据看板"标签 → 显示统计数据
    └─ 仅限已认证商家
```

### 管理后台跳转

```
admin-dashboard.html
│
├─ 点击"商家审核"标签 → 显示申请列表
│   ├─ 点击"批准" → 更新状态为 approved
│   └─ 点击"拒绝" → 更新状态为 rejected
│
├─ 点击"路线审批"标签 → 显示新路线
│   └─ 审核路线内容
│
└─ 点击"数据报表"标签 → 显示完整统计
    └─ 包含所有收益数据
```

## 💡 常见问题

### Q1: 商户端按钮不能用？
**A**: 正在修复中。暂时可通过导航中心访问。

### Q2: 页面太多太乱？
**A**: 使用 index.html 导航中心，所有页面都有清晰分类和说明。

### Q3: 手机怎么访问？
**A**: 使用 mobile-lite.html（16KB），纯 HTML 无需安装。

**A**: 所有数据使用 localStorage 保存在浏览器本地。

**A**: 清除浏览器缓存或使用隐私模式重新打开。
