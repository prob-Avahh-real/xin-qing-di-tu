# 🔄 积分系统命名调整

*调整时间：2026-04-24 19:32 | 原因：避免诈骗感，符合平台定位*

---

## ⚠️ 问题

### 原命名：功德值 ❌

**问题点**：
1. **像诈骗**：用户感觉被忽悠
2. **越权**：平台和寺庙没有合作，无权代表寺庙
3. **误导**：用户以为真的在做功德
4. **不合规**：可能涉及宗教相关监管问题

---

## ✅ 解决方案

### 新命名：积分 ✅

**优点**：
1. **正规**：标准电商/平台用语
2. **清晰**：用户一看就懂
3. **合规**：无宗教敏感
4. **准确**：符合平台定位（只是平台方，不是寺庙方）

---
