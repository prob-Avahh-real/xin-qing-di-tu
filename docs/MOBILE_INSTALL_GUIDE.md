## 📱 iOS (iPhone/iPad)

### 方法 1：添加到主屏幕（推荐）

**步骤**：

```
1. 用 Safari 打开心情地图网页
   https://your-domain.com

2. 点击底部工具栏的"分享"按钮
   📤 (正方形 + 向上箭头)

3. 向下滑动，找到"添加到主屏幕"
   点击它

4. 输入名称（默认"心情地图"）
   点击右上角"添加"

5. 完成！
   桌面上会出现心情地图的图标
```

**效果**：
- ✅ 独立 APP 图标
- ✅ 全屏显示（无 Safari 地址栏）

- ✅ 点击图标直接打开

---

### manifest.json 配置

```json
{
  "name": "心情地图",
  "short_name": "心情地图",
  "description": "今天是什么心情，就去哪里玩",
  "start_url": "/index.html",
  "display": "standalone",
  "theme_color": "#F9B572",
  "background_color": "#f5f5f5"
}
```

**说明**：
- `display: standalone` = 全屏显示
- `theme_color` = 状态栏颜色
- `start_url` = 启动页面

---

### Service Worker 功能

**离线缓存**：
- 首次访问时缓存所有页面
- 无网络时也能打开
- 有网络时自动更新

**推送通知**：
- 心愿到期提醒
- 活动通知
- 个性化推送
