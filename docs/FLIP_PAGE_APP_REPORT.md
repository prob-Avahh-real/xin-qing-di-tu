## 🎬 翻页动画

### 切换效果

```css
.page {
    position: absolute;
    transition: transform 0.3s ease-in-out;
}

.page.entering {
    transform: translateX(100%); /* 从右侧进入 */
}

.page.entering.active {
    transform: translateX(0); /* 移动到中心 */
}

.page.leaving {
    transform: translateX(-100%); /* 从左侧离开 */
}
```

### 交互流程

```
点击底部导航
    ↓
旧页面添加 .leaving 类
    ↓
新页面添加 .entering 类
    ↓
0.3 秒后
    ↓
旧页面移除所有类
新页面添加 .active 类
    ↓
翻页完成
```

## 📊 尺寸控制

### 固定高度

```css
body {
    height: 100vh;        /* 100% 屏幕高度 */
    overflow: hidden;     /* 禁止整体滚动 */
    display: flex;
    flex-direction: column;
}

.status-bar {
    height: 44px;         /* 固定 44px */
    flex-shrink: 0;       /* 不压缩 */
}

.pages-container {
    flex: 1;              /* 占据剩余空间 */
    position: relative;
    overflow: hidden;
}

.tab-bar {
    height: 60px;         /* 固定 60px */
    flex-shrink: 0;       /* 不压缩 */
}
```

### 计算结果

```
屏幕总高度：100vh
- 顶部状态栏：44px
- 底部导航栏：60px
= 页面容器：calc(100vh - 104px)

无论内容多少，都不会超出这个范围
```

## 🎯 核心特性

### 1. 页面独立

每个页面都是独立的 DOM 元素：
- 互不干扰
- 可以独立滚动
- 可以独立刷新

### 2. 单页显示

同一时间只显示一个页面：
```css
.page { display: none; }
.page.active { display: block; }
```

### 3. 状态保持

页面切换后状态保持：
- 滚动位置不变
- 数据不变
- 筛选状态不变

### 4. 动画流畅

0.3 秒过渡动画：
```css
transition: transform 0.3s ease-in-out;
```

## 🔧 技术实现

### 页面切换函数

```javascript
function switchPage(pageName, tabElement) {
    // 1. 更新底部导航状态
    document.querySelectorAll('.tab-item').forEach(t => 
        t.classList.remove('active')
    );
    tabElement.classList.add('active');
    
    // 2. 更新顶部标题
    const titles = {
        'home': '福来的心愿清单',
        'tasks': '赚功德任务',
        'orders': '我的订单',
        'profile': '个人中心'
    };
    document.getElementById('pageTitle').textContent = titles[pageName];
    
    // 3. 切换页面
    document.querySelectorAll('.page').forEach(p => {
        p.classList.remove('active', 'entering', 'leaving');
    });
    
    const targetPage = document.getElementById('page-' + pageName);
    targetPage.classList.add('entering');
    
    setTimeout(() => {
        targetPage.classList.add('active');
        targetPage.classList.remove('entering');
    }, 300);
    
    // 4. 滚动到顶部
    targetPage.querySelector('.page-content').scrollTop = 0;
}
```

## 💡 设计原则

### 手机 APP 设计原则

1. **固定范围**
   - 内容不超出屏幕
   - 通过翻页查看更多

2. **清晰架构**
   - 每个页面一个主题
   - 不混在一起

3. **流畅动画**
   - 0.3 秒过渡
   - 自然顺滑

4. **状态保持**
   - 返回时状态不变
   - 用户体验连贯
