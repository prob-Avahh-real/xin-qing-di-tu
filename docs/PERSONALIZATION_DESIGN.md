   性格：神秘有趣
   语音：语速中等，带点俏皮

**根据访问次数调整**：
```

   内容：新活动、隐藏彩蛋、季节性内容
   
50 次以上（铁粉）
   语音："您是我们的荣誉访客！有专属福利..."
   内容：专属活动、志愿者机会、内测权限
```

---

### 7. 行为偏好（AI 学习）

**根据用户行为自动学习**：
```
停留时长
   - 在某景点停留久 → 推荐类似景点
   - 快速跳过 → 减少类似内容
   
拍照行为
   - 经常拍照 → 推荐更多拍照点
   - 不拍照 → 减少拍照推荐
   
阅读深度
   - 读完长文 → 推送深度内容
   - 只看简介 → 推送简短内容
   
分享行为
   - 经常分享 → 提供分享素材
   - 不分享 → 减少分享提示
   
时间偏好
   - 上午访问多 → 上午推送
   - 周末访问 → 周末推送新内容
```

### 个性化推荐算法（简化版）

```javascript
function recommendRoute(userProfile, context) {
    const { interests, visitCount, favoriteSpots } = userProfile;
    const { time, weather, season } = context;
    
    // 基础分数
    let scores = routes.map(route => {
        let score = route.baseScore;
        
        // 兴趣匹配 +30 分
        if (route.tags.some(tag => interests.includes(tag))) {
            score += 30;
        }
        
        // 时间适配 +20 分
        if (route.bestTime === time) {
            score += 20;
        }
        
        // 天气适配 +20 分
        if (route.weatherFit.includes(weather)) {
            score += 20;
        }
        
        // 新鲜度（没去过的 +25 分）
        if (!favoriteSpots.includes(route.id)) {
            score += 25;
        }
        
        return { route, score };
    });
    
    // 排序返回
    return scores.sort((a, b) => b.score - a.score);
}
```
