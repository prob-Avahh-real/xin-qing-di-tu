## 👥 用户类型划分

### 5 类核心用户画像

| 用户类型 | 占比 | 核心需求 | 情绪状态 | 使用场景 |
|---------|------|---------|---------|---------|
| **1. 情绪疗愈型** | 35% | 释放压力、寻找平静 | 焦虑/疲惫/孤独 | 下班后、周末独处 |
| **2. 社交分享型** | 25% | 拍照打卡、朋友圈素材 | 兴奋/期待/展示欲 | 周末聚会、节假日 |
| **3. 文化探索型** | 20% | 了解历史、深度体验 | 好奇/求知/沉浸 | 文化之旅、亲子教育 |
| **4. 便捷出行型** | 15% | 快速规划、省时省力 | 匆忙/务实/效率 | 临时起意、带家人 |
| **5. 特殊纪念型** | 5% | 纪念意义、仪式感 | 怀念/感恩/祈福 | 生日、纪念日、祈福 |

## 📊 用户体验地图 - 情绪疗愈型 (35%)

### 用户画像

```
姓名：小李
年龄：28 岁
职业：互联网程序员
状态：加班两周，身心疲惫
口头禅："想一个人静静"
```

### 使用旅程

#### 阶段 1: 情绪触发 (周五晚 20:00)

**情境**: 刚结束一周加班，坐在地铁上，感觉很累

| 触点 | 用户行为 | 用户需求 | 产品设计 | 情绪曲线 |
|------|---------|---------|---------|---------|
| **打开 APP** | 看到欢迎语 | 被理解、被接纳 | "欢迎回来，今天辛苦了" | 😫 → 😌 |
| **心情选择** | 点击"EMO 治愈" | 不用说话，被懂 | 一键选择，AI 理解 | 😌 → 🤗 |
| **路线生成** | 等待 3 秒 | 快速得到答案 | 显示"福来正在为你准备..." | 🤗 → 🙂 |

**关键设计**:
```
✅ 欢迎语根据时间变化：
   - 早上："早上好，今天阳光很好"
   - 晚上："辛苦了，来放松一下吧"

✅ 心情按钮文案：
   - 不是"选择心情"
   - 而是"今天想..."
   - "想一个人静静"
   - "想被温柔对待"
   - "想找个地方发呆"

✅ 加载文案：
   - "福来正在为你挑选最安静的角落..."
   - "龙龙已经准备好故事了"
```

#### 阶段 2: 路线体验 (周六下午 14:00)

**情境**: 独自来到龙华寺，寻找内心平静

| 触点 | 用户行为 | 用户需求 | 产品设计 | 情绪曲线 |
|------|---------|---------|---------|---------|
| **交通指引** | 查看"怎么来" | 不想迷路 | 详细指引 + 停车推荐 | 🙂 → 😊 |
| **龙龙讲故事** | 点击语音 | 有人陪伴 | 温柔童声讲历史 | 😊 → 🥰 |
| **猫咪彩蛋** | 发现福来 | 惊喜感 | "摸左耳招桃花" | 🥰 → 😄 |
| **静坐时刻** | 寺庙休息 | 不被打扰 | 推荐"最佳静坐点" | 😄 → 🧘 |

**关键设计**:
```
✅ 语音语调：
   - 语速慢 0.9 倍
   - 音调温柔 1.1
   - 句间停顿 300ms
   - "这里是龙华寺，已经等待了你 1000 年..."

✅ 彩蛋设计：
   - 不是"打卡点"
   - 而是"福来在这里等你"
   - "摸摸我的耳朵，会有好运哦"

✅ 静坐推荐：
   - "这个角落最安静"
   - "下午 3 点阳光正好"
   - "适合一个人发呆 15 分钟"
```

#### 阶段 3: 情绪释放 (周六傍晚 17:00)

**情境**: 完成路线，感觉轻松了很多

| 触点 | 用户行为 | 用户需求 | 产品设计 | 情绪曲线 |
|------|---------|---------|---------|---------|
| **积分奖励** | 获得 50 积分 | 被认可 | "你今天很棒" | 😊 → 🥳 |
| **许愿池** | 写下心愿 | 情绪出口 | 漂流瓶 + 时间胶囊 | 🥳 → 🌟 |
| **朋友圈分享** | 分享感受 | 被理解 | 生成精美卡片 | 🌟 → 💕 |

**关键设计**:
```
✅ 积分文案：
   - 不是"获得 50 积分"
   - 而是"你今天照顾了自己的心情，很棒"
   - "福来为你准备了小礼物"

✅ 许愿池：
   - "把烦恼装进漂流瓶"
   - "让时间带走疲惫"
   - "明年今天的你会感谢现在"

✅ 分享卡片：
   - 不是"我来过"
   - 而是"今天被治愈了"
   - "龙华寺的猫说：你值得被温柔对待"
```

## 💡 情感化设计清单

### 让用户感到"被爱"的细节

#### 1. 文案温度

```
❌ 冷冰冰：
   "获得 50 积分"
   "路线生成成功"
   "点击查看详情"

✅ 有温度：
   "你今天照顾了自己的心情，很棒"
   "福来已经为你准备好路线了"
   "龙龙想给你讲个故事"
```

#### 2. 情绪反馈

```
✅ 用户完成路线：
   "这条路线你走了 2 小时，辛苦了"
   "福来看到你全程听完故事，很认真"

✅ 用户写下心愿：
   "这个心愿很重要，福来会帮你守护"
   "明年今天的你会感谢现在的自己"

✅ 用户获得积分：
   "积分不是目的，你的开心才是"
   "福来为你准备了小惊喜"
```

#### 3. 贴心提醒

```
✅ 天气关怀：
   "今天阳光很好，记得涂防晒"
   "下午可能会下雨，带把伞"

✅ 时间关怀：
   "现在已经 5 点了，寺庙快关门了"
   "最后一班地铁是 22:30，注意时间"

✅ 身体关怀：
   "走了 1 小时，休息一下喝口水"
   "前面有休息区，可以坐 10 分钟"
```

#### 4. 意外惊喜

```
✅ 彩蛋设计：
   "今天是你的生日，福来祝你生日快乐"
   "这是你第 3 次来龙华寺，老朋友们"

   "你发现了隐藏打卡点！获得'探索者'徽章"
   "连续签到 7 天，解锁'坚持者'称号"
```

## 📝 总结

### 心情地图 ≠ 消费工具

```
心情地图 = 情绪出口 + 贴心伙伴 + 问题解决者
```

### 用户不是消费者，是被理解的朋友

```
❌ "这个用户会消费什么？"
✅ "这个用户需要什么？"
❌ "怎么让用户多花钱？"
✅ "怎么让用户更开心？"
```

### 每个页面都是情绪推进器

```
首页 → 被理解
路线 → 被关怀
体验 → 被陪伴
完成 → 被认可
分享 → 被认同
```

### 最终目标

**让用户在离开 APP 时说：**
> "今天被治愈了，谢谢福来。"
