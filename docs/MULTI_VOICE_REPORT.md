## 🎬 使用方式

### 快速试听
```
1. 打开页面
2. 点击任意角色卡片（如"福来"）
3. 自动配置声音和参数
4. 点击"试听"按钮
```

### 自定义配置
```
1. 选择声音类型（4 种）
2. 调节语速/音调/音量
3. 输入测试文本
4. 点击"播放"
```
