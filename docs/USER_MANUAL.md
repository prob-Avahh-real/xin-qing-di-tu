## ⚠️ 常见问题

### Q1: 语音不播放？
**解决**：
```
1. 检查浏览器是否支持 Web Speech API
2. Chrome/Edge 支持最好
3. 手机浏览器需要授权
```

### Q2: 地图打不开？
**解决**：
```
1. 需要联网
2. 高德 API key 正常
3. 手机需要安装高德地图 APP
```

### Q3: 积分商城翻页卡顿？
**解决**：
```
1. 清理浏览器缓存
2. 重启浏览器
3. 使用 Chrome/Edge
```

### Q4: 数据不保存？
**解决**：
```
1. 使用 localStorage
2. 清除缓存会丢失数据
3. 建议不要清理缓存
```
