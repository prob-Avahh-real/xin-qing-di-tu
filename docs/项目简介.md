**LYCC 2026 龙华·黑客松参赛作品**

---

## 📌 一句话介绍

**今天是什么心情，就去哪里玩**

心情地图是一个基于 AI 的情感出行指南 APP，根据用户当下的心情智能推荐个性化游玩路线，让每一次出行都成为一次心灵的治愈之旅。

---

## 🎯 痛点分析

### 现代年轻人出行困境

| 痛点 | 表现 | 影响 |
|------|------|------|
| **选择困难** | 想去玩但不知道去哪里 | 浪费时间纠结 |
| **情绪忽视** | 传统推荐只考虑地点，不考虑心情 | 游玩体验差 |
| **文化缺失** | 打卡式旅游，缺乏深度体验 | 走马观花 |
| **社交孤立** | 一个人出行缺乏陪伴感 | 孤独感强 |
| **意义缺失** | 游玩后没有收获和记忆 | 空虚感 |

---

## 💡 解决方案

### 心情地图的核心功能

#### 1️⃣ 情绪路线推荐
- **12 种情绪类型**：EMO 治愈、散心、拍照、聚会、文艺、约会、亲子、美食、祈福、运动、躺平、探索
- **AI 智能规划**：根据情绪自动生成 8-12 个景点的完整路线
- **语音讲解**：青春活力少女音，像朋友一样陪伴

#### 2️⃣ 游戏化体验
- **积分系统**：完成任务赚积分（打卡、分享、阅读知识库）
- **兑换商城**：文创产品、体验券、公益捐赠
- **许愿池**：时间胶囊功能，给未来的自己写信

#### 3️⃣ 深度文化体验
- **知识库**：6 大分类（历史/人文/美食/拍照/彩蛋/活动）
- **真实图片**：18 张实拍龙华照片，拒绝占位图
- **POI 详情**：龙龙讲故事、弹幕墙、挑战任务、隐藏彩蛋

#### 4️⃣ 商户生态
- **商户入驻**：3 级权限管理（顾客/商户/管理员）
- **审核流程**：完整的商户/路线/活动审核机制
- **公益定位**：非宗教功能，透明公益，自愿消费

## 🎨 产品特色

### 与其他平台的区别

| 平台 | 定位 | 特点 | 不足 |
|------|------|------|------|
| **高德地图** | 工具型导航 | 路线规划准确 | 缺乏情感维度 |
| **马蜂窝** | 旅游攻略 | 内容专业 | 偏重长行程 |
| **小红书** | 种草社区 | 用户生成内容 | 信息碎片化 |
| **大众点评** | 本地生活 | 商家信息全 | 商业化过重 |
| **心情地图** | 情感出行指南 | AI 个性化 × 在地文化 | 新创产品 |

### 核心竞争优势

```
✅ 情感维度创新 - 首个以"心情"为核心的出行 APP
✅ AI 个性化 - 千人千面，每个人看到不同的推荐
✅ 文化深度 - 深耕龙华在地文化，不做泛泛内容
✅ 游戏化设计 - 积分/任务/许愿池，提升用户粘性
✅ 公益定位 - 非商业化过重，用户信任度高
```

## 🛠️ 技术架构

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | Vue 3 + TypeScript | 现代化开发体验 |
| **构建工具** | Vite | 秒级热更新 |
| **样式方案** | Tailwind CSS | 原子化 CSS |
| **地图服务** | 高德地图 API | 路径规划/地理编码 |
| **语音合成** | Web Speech API | 浏览器原生支持 |
| **数据存储** | localStorage | 离线持久化 |
| **PWA 支持** | manifest.json + Service Worker | 可安装到桌面 |

### 核心 API

```javascript
// 高德地图路径规划
AMap.Walking({map: map}).search(startLoc, endLoc, callback)

// 地理编码
AMap.Geocoder({city: '上海'}).getLocation(address, callback)

// 语音合成
const utterance = new SpeechSynthesisUtterance(text)
utterance.rate = 1.1
utterance.pitch = 1.3
speechSynthesis.speak(utterance)
```
