## 🔍 问题诊断

### 用户反馈
- **问题**：语音太机械，很难听
- **表现**：像机器人念稿，没有感情
- **影响**：用户体验差，不愿意听

### 根本原因

| 问题 | 表现 | 原因 |
|------|------|------|
| **单一语调** | 全程一个音调 | 没有根据情感调整 pitch |
| **没有停顿** | 一气呵成 | 没有智能断句 |
| **没有情感** | 开心/治愈都一样 | 没有情感预设配置 |
| **语速固定** | 不知道哪里快慢 | rate 参数固定 |
| **没有音效** | 干巴巴的语音 | 缺少开场/结束音效 |

---

## ✅ 解决方案

### 核心设计理念

**像真人一样说话 = 情感语调 + 智能断句 + 音效衬托**

```
真人说话特点：
├─ 情感起伏（开心时音调高，难过时音调低）
├─ 呼吸停顿（句子之间有停顿）
├─ 语速变化（重要的地方慢，兴奋的地方快）
└─ 语气词（嗯、啊、哇等）
```

## ✂️ 智能断句算法

### 问题分析

**不断句的语音**：
```
"我知道你很难过让福来抱抱你摸摸它的耳朵感受这份温暖一切都会好起来的"
```
❌ 像机器人，没有呼吸感

### 解决方案

**智能断句**：
```javascript
function smartSplit(text) {
  // 按句号、感叹号、问号分割
  const sentences = text.split(/([.!?])/g)
    .map(s => s.trim())
    .filter(s => s.length > 0);
  
  // 重新组合成完整句子
  const result = [];
  for (let i = 0; i < sentences.length; i += 2) {
    const sentence = sentences[i] + (sentences[i+1] || '');
    result.push(sentence);
  }
  return result;
}
```

**断句后的语音**：
```
"我知道你很难过。（停顿 800ms）
让福来抱抱你。（停顿 800ms）
摸摸它的耳朵，感受这份温暖。（停顿 800ms）
一切都会好起来的。"
```
✅ 像真人，有呼吸感

## 🔧 集成到主 APP

### 方式 1：替换现有 TTS

**修改 `src/utils/tts.ts`**：
```typescript
// 删除旧代码，替换为 tts-v2.ts 的内容
// 或者直接重命名：
mv src/utils/tts-v2.ts src/utils/tts.ts
```

### 方式 2：双系统并存

**保留旧文件，新增情感函数**：
```typescript
// 在 App.vue 中
import { playEmotionalTTS } from './utils/tts-v2'

// 调用
playEmotionalTTS('我知道你很难过', 'sad', {
  withSoundEffect: true,
  withPrefix: true
})
```

### 方式 3：Vue 组件封装

**创建语音播报组件**：
```vue
<!-- src/components/VoiceGuide.vue -->
<template>
  <button @click="playGuide">🔊 语音导览</button>
</template>

<script setup lang="ts">
import { playEmotionalTTS } from './utils/tts-v2'

const props = defineProps({
  text: String,
  emotion: String
})

function playGuide() {
  playEmotionalTTS(props.text, props.emotion, {
    withSoundEffect: true,
    withPrefix: true
  })
}
</script>
```

## 💡 最佳实践

### 1. 选择合适的时机

**适合用语音的场景**：
- ✅ 景点介绍（配合地图）
- ✅ 情感引导（治愈时刻）
- ✅ 路线开始/结束提示
- ✅ 彩蛋发现提示

**不适合用语音的场景**：
- ❌ 安静环境（如寺庙内）
- ❌ 用户可能静音的场景
- ❌ 文字已足够清晰的场景

---

### 2. 控制语音长度

**推荐长度**：
- 景点介绍：30-60 秒
- 情感引导：1-2 分钟
- 路线提示：10-20 秒

**避免**：
- ❌ 超过 3 分钟的长语音
- ❌ 连续播放多条语音
- ❌ 自动循环播放

---

### 3. 提供关闭选项

**始终提供**：
- ✅ 暂停/恢复按钮
- ✅ 音量调节
- ✅ 关闭语音选项

**尊重用户选择**：
- 记住用户的偏好设置
- 默认不自动播放（需要点击）
- 在安静场景自动降低音量
