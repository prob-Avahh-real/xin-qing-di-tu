## ❓ 问答环节准备

### 可能的问题及回答

#### Q1: 你们和高德地图有什么区别？

**A**: 高德是工具型导航，核心是"怎么去"；我们是情感出行指南，核心是"去哪里 + 为什么去"。

高德不会关心你今天什么心情，我们会。这是情感维度的创新。

#### Q2: 你们的用户从哪里来？

**A**: 初期通过龙华庙会活动获客，与庙会合作设置打卡点，游客扫码使用 APP 打卡赚积分。

后期通过社交媒体分享、用户邀请、企业定制等渠道扩展。

#### Q3: 如何保证内容质量？

**A**: 我们有严格的内容审核机制：
1. 所有内容来自权威来源（维基百科、官方资料）
2. 图片使用 Wikimedia Commons 等版权清晰的实拍图
3. 管理后台有专门的审核流程，商户/路线/活动都需要审批

#### Q4: 盈利模式是否可持续？

**A**: 我们首年目标 100 万收入，基于 5 大收入来源的多元化模型。

关键是公益定位建立用户信任，信任带来持续消费。功德主计划是核心，用户自愿捐赠，月度公示，透明可信。

#### Q5: 技术壁垒是什么？

**A**: 说实话，技术本身壁垒不高，Vue 3、高德 API、Web Speech 都是成熟技术。

真正的壁垒是：**情感维度设计 + 在地文化深耕 + 用户情感连接**。

这些需要时间去积累，不是抄代码就能抄走的。

#### Q6: 为什么选择 PWA 而不是原生 APP？

**A**: 三个原因：
1. **开发效率**：黑客松只有 2 天，PWA 可以快速上线
2. **用户体验**：无需下载，扫码即用，降低门槛
3. **成本考虑**：原生 APP 需要上架审核，维护成本高

后续如果融资，我们会考虑开发原生 APP，但 PWA 会一直保留作为轻量版本。

#### Q7: 你们有考虑过竞争吗？如果小红书也做这个功能怎么办？

**A**: 好问题。

首先，小红书的核心是"种草社区"，用户生成内容，信息碎片化，不适合做深度路线规划。

其次，我们深耕龙华在地文化，这是需要时间去积累的，大公司不会为了一个小区域投入这么多精力。

最后，**先发优势**很重要。我们先占领用户心智，后来者很难超越。

当然，我们会持续迭代，保持创新。

## 🎯 演讲技巧提示

### 语速控制

```
正常语速：每分钟 180-200 字
5 分钟：约 900-1000 字
本稿字数：约 1000 字（含停顿）
```

### 眼神交流

```
开场：扫视全场，与每位评委眼神接触 2-3 秒
演示：边操作边讲解，不要背对观众
重点：强调关键信息时，盯着主评委
结尾：真诚微笑，等待掌声
```

### 肢体语言

```
手势：自然张开，不要插兜或抱胸
站姿：挺直，重心在两脚之间
移动：适当走动，不要一直站在原地
```

### 应对紧张

```
深呼吸：上台前深呼吸 3 次
心理暗示："我已经准备好了"
语速：紧张时容易说快，有意识放慢
停顿：忘记台词时，停顿 2 秒整理思路
```
