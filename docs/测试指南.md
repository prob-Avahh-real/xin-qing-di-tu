## 🎤 语音测试专项

### 测试文件

**打开**: `youth-voice-test.html`

### 测试步骤

```
1. 选择"青春活力"预设
2. 点击"播放试听"
3. 听测试文本:
   - "为你推荐这条路线，希望你玩得开心！"
   - "这里是龙华寺，千年古刹，超级灵验哦！"
   - "加油！你是最棒的！"
   - "今天天气真好，适合出来玩呢！"
   - "叮！你的好运已送达，请查收～"
```

### 评估标准

| 维度 | 优秀 ⭐⭐⭐ | 良好 ⭐⭐ | 需改进 ⭐ |
|------|----------|--------|---------|
| **音调** | 明亮不刺耳 | 稍微偏高/低 | 太尖或太沉 |
| **语速** | 轻快自然 | 稍快/稍慢 | 太快或太慢 |
| **清晰度** | 每个字清楚 | 个别字模糊 | 听不清 |
| **情感** | 轻松愉快 | 平淡 | 机械无感情 |
| **整体** | 年轻人喜欢 | 可接受 | 需要调整 |

### 推荐参数

```
语速：1.1 (范围 0.5-2.0)
音调：1.3 (范围 0.5-2.0)
音量：1.0 (范围 0.1-1.0)
```

### 其他预设

- **温柔姐姐**: 语速 0.95, 音调 1.1 (温暖治愈)
- **可爱萝莉**: 语速 1.3, 音调 1.6 (超级可爱)
- **活力四射**: 语速 1.2, 音调 1.4 (元气满满)

## 🐛 常见问题排查

### 问题 1: 页面显示乱码

**症状**: 中文显示为 `` 或奇怪的符号

**解决方案**:
```
1. 检查文件编码是否为 UTF-8
2. 用文本编辑器打开 → 另存为 → 选择 UTF-8
3. 使用修复版文件 (如 points-mall-app-fixed.html)
4. 清除浏览器缓存后重新打开
```

---

### 问题 2: 语音播放失败

**症状**: 点击语音按钮没声音

**解决方案**:
```
1. 检查浏览器是否支持语音合成
2. 查看浏览器控制台错误 (F12)
3. 确认语音参数正确 (rate 1.1, pitch 1.3)
4. 尝试更换浏览器 (推荐 Edge/Chrome)
5. 检查系统音量是否打开
```

---

### 问题 3: 地图不显示

**症状**: 地图区域空白或显示错误

**解决方案**:
```
1. 检查网络连接
2. 确认 AMap API Key 有效
3. 查看浏览器控制台错误
4. 尝试刷新页面
5. 检查是否被浏览器拦截
```

---

### 问题 4: localStorage 不保存

**症状**: 刷新页面后数据丢失

**解决方案**:
```
1. 检查浏览器是否允许 localStorage
2. 确认没有开启"无痕模式"
3. 查看浏览器控制台错误
4. 尝试清除缓存后重新测试
```

---

### 问题 5: 积分商城打不开

**症状**: 页面显示乱码或空白

**解决方案**:
```
1. 使用修复版文件：points-mall-app-fixed.html
2. 删除原文件：points-mall-app.html
3. 清除浏览器缓存
4. 重新打开修复版文件
```
