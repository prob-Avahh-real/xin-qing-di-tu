# 🏪 商户合作与审核系统

*最后更新：2026-04-24 | 版本：v1.0*

---

## 📋 系统概述

**核心原则**: 数据权限分离，商业机密保护

```
客户看到的：游玩路线 + 活动信息 + 优惠券
商户看到的：合作申请 + 脱敏数据 + 结算信息
管理员看到的：审核后台 + 完整数据 + 收益统计
```

---

## 🔐 权限分离设计

### 页面访问权限

| 页面 | 客户 | 商户 | 管理员 | 说明 |
|------|------|------|--------|------|
| **路线展示页** | ✅ 公开 | ✅ 可见 | ✅ 可见 | 所有用户可看 |
| **情绪路线详情** | ✅ 公开 | ✅ 可见 | ✅ 可见 | 含商户信息 |
| **商户合作页** | ❌ 隐藏 | ✅ 可申请 | ✅ 可管理 | 仅商户/管理员 |
| **管理后台** | ❌ 隐藏 | ❌ 隐藏 | ✅ 独占 | 管理员专属 |
| **收益数据** | ❌ 隐藏 | ⚠️ 仅自己 | ✅ 全部 | 商业机密 |
| **用户数据** | ❌ 隐藏 | ❌ 隐藏 | ✅ 可见 | 隐私保护 |

### 数据脱敏规则

| 数据类型 | 客户看到 | 商户看到 | 管理员看到 |
|---------|---------|---------|-----------|
| **路线总曝光** | ❌ 不显示 | ✅ 仅自己商户 | ✅ 全部商户 |
| **点击到店数** | ❌ 不显示 | ✅ 仅自己商户 | ✅ 全部商户 |
| **优惠券核销** | ❌ 不显示 | ✅ 仅自己商户 | ✅ 全部商户 |
| **用户评分** | ✅ 公开 | ✅ 公开 | ✅ 公开 |
| **收益金额** | ❌ 不显示 | ⚠️ 仅自己结算 | ✅ 全部统计 |
| **用户信息** | - | ❌ 不显示 | ✅ 完整信息 |

## 🔍 审核管理后台

### 审核类型

| 审核类型 | 审核内容 | 审核标准 | 时限 |
|---------|---------|---------|------|
| **商户入驻** | 资质真实性、经营范围 | 营业执照、环境卫生 | 3 工作日 |
| **路线加入** | 商户是否符合路线主题 | 情绪匹配、服务质量 | 2 工作日 |
| **活动上线** | 活动内容、优惠力度 | 真实性、吸引力 | 1 工作日 |

### 审核流程

```
商户提交申请
    ↓
系统自动初审（格式检查）
    ↓
管理员人工复审（资质核实）
    ↓
通过 → 签约上线
    ↓
拒绝 → 说明理由，可重新申请
```

### 审核操作

**通过：**
- 更新状态为"已通过"
- 发送通知短信/邮件
- 商户可登录后台
- 加入对应情绪路线

**拒绝：**
- 必须填写拒绝理由
- 状态更新为"已拒绝"
- 发送通知说明原因
- 商户可补充材料重新申请

### 管理后台功能

**数据概览：**
- 合作商户总数
- 上线路线数量
- 待审核数量
- 今日用户数

**商户审核：**
- 筛选（类型/状态）
- 搜索（商户名称）
- 查看详情
- 通过/拒绝操作

**路线审核：**
- 按情绪筛选
- 按状态筛选
- 路线详情
- 上架/下架操作

**活动审核：**
- 活动内容审核
- 优惠力度评估
- 上线时间确认

## 🔒 安全机制

### 数据保护

| 措施 | 实现方式 | 保护对象 |
|------|---------|---------|
| **权限分离** | 角色访问控制 | 商业机密 |
| **数据脱敏** | 前端过滤 + 后端限制 | 商户隐私 |
| **用户隐私** | 不向商户展示 | 个人信息 |
| **操作日志** | 记录所有审核操作 | 可追溯 |

### 审核规范

**禁止行为：**
- ❌ 向客户展示收益数据
- ❌ 向商户展示其他商户数据
- ❌ 向商户展示用户个人信息
- ❌ 无拒绝理由的审核拒绝

**必须行为：**
- ✅ 所有审核必须有记录
- ✅ 拒绝必须说明理由
- ✅ 敏感数据必须脱敏
- ✅ 操作必须有日志

## 📋 入驻审核标准

### 基础资质

| 要求 | 说明 | 验证方式 |
|------|------|---------|
| **营业执照** | 合法经营 | 上传照片 |
| **经营范围** | 与申请类型一致 | 人工核对 |
| **环境卫生** | 符合卫生标准 | 实地考察/照片 |
| **信用记录** | 无不良记录 | 征信查询 |

### 服务质量

| 要求 | 说明 | 验证方式 |
|------|------|---------|
| **服务态度** | 热情友好 | 用户反馈 |
| **产品质量** | 符合标准 | 用户评分 |
| **价格透明** | 明码标价 | 实地考察 |
| **履约能力** | 能接待预约 | 历史数据 |

### 路线匹配度

| 要求 | 说明 | 验证方式 |
|------|------|---------|
| **情绪主题** | 符合路线定位 | 人工评估 |
| **地理位置** | 在龙华区域内 | 地图核实 |
| **营业时间** | 覆盖游客高峰 | 信息核对 |
| **接待能力** | 满足客流需求 | 实地考察 |

## 🎯 拒绝理由模板

### 资质问题

```
❌ 营业执照不清晰，请重新上传
❌ 经营范围与申请类型不符
❌ 营业执照已过期，请更新后重新申请
```

### 服务问题

```
❌ 用户评分低于 3.5 分，请提升服务质量
❌ 收到多起投诉，请整改后重新申请
❌ 实地考察不通过，请改善环境卫生
```

### 匹配问题

```
❌ 商户位置不在龙华区域内
❌ 营业时间与路线需求不匹配
❌ 情绪主题不符（例如：快餐店申请加入文艺路线）
```

## 📈 数据指标

### 商户端

| 指标 | 定义 | 计算方式 |
|------|------|---------|
| **曝光量** | 路线展示次数 | 用户浏览路线页次数 |
| **点击率** | 点击/曝光 | 点击商户详情次数 / 曝光量 |
| **到店率** | 核销/点击 | 优惠券核销次数 / 点击次数 |
| **评分** | 用户评价 | 平均星级（1-5 分） |

### 平台端

| 指标 | 定义 | 计算方式 |
|------|------|---------|
| **入驻转化率** | 通过/申请 | 审核通过数 / 申请总数 |
| **审核时效** | 平均审核时间 | 总耗时 / 审核数量 |
| **商户留存率** | 活跃/总商户 | 月活商户数 / 总商户数 |
| **路线质量** | 平均评分 | 所有路线评分平均值 |
