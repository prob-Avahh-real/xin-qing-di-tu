## 📊 功能模块说明

### 1️⃣ 主 APP (business-pro-rich-routes.html)

**功能**：
- 12 种情绪路线选择
- AI 智能路线规划
- 8-12 个景点展示
- 语音讲解播放
- 背景音乐切换

**演示要点**：
```
✅ 点击"EMO 求治愈"
✅ 展示生成的路线
✅ 播放语音讲解
✅ 展示景点详情
```

---

### 2️⃣ 积分商城 (points-mall-app-fixed.html)

**功能**：
- 4 个页面（首页/任务/订单/我的）
- 8 个赚积分任务
- 10 种兑换商品
- 积分持久化存储
- 龙华庙会倒计时

**演示要点**：
```
✅ 展示积分余额
✅ 查看任务列表
✅ 点击兑换商品
✅ 展示倒计时
```

---

### 3️⃣ 知识库 (knowledge-base.html)

**功能**：
- 6 大分类（历史/人文/美食/拍照/彩蛋/活动）
- 18 张真实龙华照片
- 卡片式布局
- 丰富的文化内容

**演示要点**：
```
✅ 切换不同分类
✅ 展示真实照片
✅ 阅读文化内容
```

---

### 4️⃣ 许愿池 (wishing-pool.html)

**功能**：
- 5 种漂流瓶样式
- 自定义开启日期
- 邮件提醒功能
- 倒计时显示

**演示要点**：
```
✅ 选择瓶子样式
✅ 输入愿望
✅ 选择开启日期
✅ 投入许愿池
```

---

### 5️⃣ 小游戏 (接福来 - 小游戏.html)

**功能**：
- 接福来猫得分
- 避开炸弹
- 接金彩蛋双倍分
- 最高分记录

**演示要点**：
```
✅ 快速演示一局
✅ 展示得分
✅ 展示最高分
```
