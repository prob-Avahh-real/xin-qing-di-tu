## 📱 PWA 安装指南

### 什么是 PWA？

PWA（渐进式网页应用）是一种可以像原生 APP 一样安装的网页应用。

### 安装步骤

#### iOS (Safari)
```
1. 用 Safari 打开网页
2. 点击底部"分享"按钮
3. 滑动找到"添加到主屏幕"
4. 点击右上角"添加"
5. 桌面出现"心情地图"图标
```

#### Android (Chrome)
```
1. 用 Chrome 打开网页
2. 点击右上角"⋮"菜单
3. 点击"添加到主屏幕"
4. 点击"添加"
5. 桌面出现"心情地图"图标
```

### PWA 优势
```
✅ 可安装到桌面
✅ 离线可用
✅ 全屏显示（无浏览器地址栏）
✅ 自动更新
✅ 无需应用商店审核
```

## 🔧 常见问题

### Q1: 为什么语音播放不了？

**A**: 
```
1. 检查浏览器是否支持 Web Speech API
2. 确保音量已打开
3. 刷新页面试试
4. 用 Chrome 或 Safari 浏览器
```

### Q2: 地图加载失败怎么办？

**A**:
```
1. 检查网络连接
2. 刷新页面
3. 查看浏览器控制台（F12）
4. 高德地图 API 可能需要科学上网
```

### Q3: 积分保存不了？

**A**:
```
1. 检查浏览器是否允许 localStorage
2. 不要用隐私模式
3. 清除浏览器缓存后重试
```

### Q4: 手机无法打开？

**A**:
```
1. 确保文件完整传输
2. 用正确的浏览器（Safari/Chrome）
3. 文件扩展名必须是 .html
4. 重新传输文件试试
```

### Q5: PWA 安装不了？

**A**:
```
1. 必须用 HTTPS 或 localhost
2. iOS 必须用 Safari
3. Android 必须用 Chrome
4. 检查 manifest.json 和 sw.js 是否存在
```
