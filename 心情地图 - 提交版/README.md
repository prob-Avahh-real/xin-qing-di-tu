Track 3.2 青年出行新体验 - 体验优先的出行路径设计

---

## 🎯 项目简介

心情地图是一款专为青年群体设计的情感化出行指南 APP，通过 AI 个性化推荐，根据用户当下的心情生成专属游玩路线。

**核心创新**:
- ✅ 12 种情感路线设计 (业内首创)
- ✅ AI 个性化推荐 + 语音导览
- ✅ 情感化 IP 设计 (福来守护猫)
- ✅ 时间胶囊许愿池
- ✅ AR 打卡印章 + 弹幕墙
- ✅ 用户留存系统 (怎么来→怎么玩→怎么去)

## 🎮 使用指南

### 核心功能流程

#### 1. 心情路线体验

```
打开导航中心 → 点击"主 APP" → 选择心情 (12 种)
→ AI 生成路线 → 查看地图 → 听音乐 → 听语音讲解
→ 打卡景点 → 获得积分 → 分享朋友圈
```

#### 2. 门票预订

```
打开导航中心 → 点击"门票"Tab → 选择票型
→ 填写订单 → 支付 → 获得电子票 → 扫码入园
```

#### 3. 积分商城

```
打开导航中心 → 点击"商城"Tab → 浏览商品
→ 选择兑换 → 扣除积分 → 获得奖品
```

#### 4. 许愿池

```
打开导航中心 → 点击"许愿池" → 选择瓶子
→ 填写心愿 → 设置开启时间 → 填写邮箱
→ 沉入池底 → 到期邮件提醒
```

### 商户端流程

#### 商家入驻

```
导航中心 → 我的 → 商户入驻 → 填写资料
→ 提交审核 → 等待批准 → 成为认证商家
```

#### 管理审核

```
导航中心 → 我的 → 管理后台 → 查看申请
→ 审核资料 → 批准/拒绝
```

## 💡 创新亮点

### 1. 12 种情感路线 (业内首创)

```
治愈系 | 散心 | 拍照 | 聚会 | 文艺 | 约会
亲子 | 美食 | 祈福 | 运动 | 躺平 | 探索
```

每种情感对应 8-12 个景点，共 120+ 景点推荐。

### 2. AI 个性化推荐

根据用户心情、偏好、时间，AI 生成专属路线。

### 3. 情感化 IP 设计

- **福来守护猫** - 陪伴用户，增加情感连接
- **龙龙讲故事** - 语音讲解，文化传播

### 4. 时间胶囊许愿池

写下心愿，设置未来开启时间 (1 天 -1 年)，到期邮件提醒。

### 5. 用户留存系统

每个页面都有：
- **怎么来** - 交通指引
- **怎么玩** - 游玩攻略
- **怎么去** - 下一站推荐

让用户留在 APP 里，而不是看完就走。

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (Vanilla)
- **地图**: 高德地图 API (Key: 03e7166e1e73fbe7d922efa31319be77)
- **AI**: 豆包 API (可选，代码已集成)
- **搜索**: Tavily API (可选，代码已集成)
- **PWA**: manifest.json + Service Worker
- **存储**: localStorage (订单、积分、心愿)
- **语音**: SpeechSynthesis API (浏览器原生)
- **音乐**: Pixabay 免费音乐库

## 📱 PWA 安装指南
