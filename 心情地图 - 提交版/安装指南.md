# 🎯 心情地图 — 安装与使用指南

---

## 一、5 秒快速上手

1. **解压** ZIP 包
2. **双击** `心情地图 - 导航中心.html`
3. 开始使用 ✅

> 无需服务器、无需安装任何软件，Windows / macOS / 手机浏览器直接打开。

---

## 二、如何安装为手机 APP（PWA）

### Android（Chrome）
1. 用 Chrome 打开 `心情地图 - 导航中心.html`
2. 点击浏览器右上角 **⋮ 菜单**
3. 选择 **「添加到主屏幕」**（或「安装应用」）
4. 完成 🎉 — 手机桌面出现心情地图图标

### iPhone / iPad（Safari）
1. 用 Safari 打开 `心情地图 - 导航中心.html`
2. 点击底部 **分享按钮 □↑**
3. 向下滚动，点击 **「添加到主屏幕」**
4. 点击右上角 **「添加」** 完成 🎉

> 安装后即可离线使用，无网络也能打开！

## 四、离线使用说明

本项目支持 **PWA 离线缓存**：
- 首次打开后，浏览器自动缓存所有资源
- 之后即使没有网络也可以正常使用
- 如需更新，清理浏览器缓存后重新打开即可

## 五、常见问题

**Q：打开后页面空白或图片不显示？**
> 请确保 ZIP 包完整解压，且所有文件在同一文件夹内，不要嵌套多层目录。

**Q：微信里打不开？**
> 微信内置浏览器对 PWA 支持有限。建议：复制链接 → 用手机系统浏览器（Safari / Chrome）打开。

**Q：想放到服务器上运行？**
> 将整个文件夹上传至任意 Web 服务器（如 Nginx、Apache、GitHub Pages），直接访问 `心情地图 - 导航中心.html` 即可。
